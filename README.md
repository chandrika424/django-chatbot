Django Chatbot

This is a chatbot web application developed using Python and Django.

Features
Chat interface for users
Django backend
Stores chat messages
Handles user questions and responses
Uses SQLite database
Django templates for the user interface
Technologies
Python
Django
SQLite
HTML/CSS
Git & GitHub
How to Run

Clone the project:

git clone https://github.com/chandrika424/django-chatbot.git

Go to the project folder:

cd django-chatbot

Install the required packages:

pip install -r requirements.txt

Run migrations:

python manage.py migrate

Start the server:

python manage.py runserver

Open:

http://127.0.0.1:8000/
Project Structure

The project contains a Django application called chat and the main Django project chatbot_project.
